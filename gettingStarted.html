Vercel — Getting Started

Para iniciar un proyecto en Vercel se siguen pasos sencillos que integran GitHub, GitLab o Bitbucket.

Pasos principales

  1. Crear cuenta en Vercel (gratis con GitHub).
  2. Importar un repositorio existente o crear un nuevo proyecto.
  3. Vercel detecta automáticamente el framework y configuración del proyecto.
  4. Con un clic se despliega el sitio con un dominio gratuito (*.vercel.app).

Vercel ofrece integración continua: cada vez que haces un commit en tu repositorio, se genera una nueva versión desplegada automáticamente.
